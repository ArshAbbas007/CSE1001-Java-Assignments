# Introduction to Computer Programming (CSE1001) - Java Assignments

This repository contains my solved Java lab assignments for **CSE1001** at **SOA ITER**, Bhubaneswar.

### 📂 Uploaded Files

* **`Java_Command_line_arguments.pdf`** — Programs using command-line arguments, basic arithmetic, `Math` functions, and type casting.
* **`java_statements_keyboard_inputs.pdf`** — Elementary programming exercises handling interactive keyboard input via `Scanner`.
* **`Java_Conditional_statements.pdf`** — Decision-making programs using `if-else` ladders, nested conditions, `switch` statements, and logical operators.
* **`Java_Iterative_looping.pdf`** — Looping and pattern logic implemented with `for`, `while`, and `do-while` loops.
